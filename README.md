> 测试结果零保留（2026-10-17）：完整测试已获授权，结果仅在终端/内存显示。已改造入口的必要工作文件使用临时目录并清理，不保存报告、日志、截图或 profile；旧硬件/安装脚本须先核对。Mac 117 个旧占用目录和 Windows 349 个此前跳过目录不重试；当前 Windows 工作对 macos/ 只读。入口与边界见[测试说明](shared/test/README.md)。

面向 Windows x64/macOS Apple Silicon（arm64）共同开发的桌面面试准备应用，发行目标为 Windows x64 和 macOS Apple Silicon。可选 ChatGPT 或 GitHub Copilot 聊天、个人信息与简历、本地知识库检索与 RAG、本地语音输入、独立面试悬浮窗口和面试记录；Mac 具有原生音频、系统窗口和独立安装包构建，采用免费签名更新方案，不以 Intel Mac 为支持目标。

当前源码版本为 **0.2.1**。Windows x64 与 Mac Apple Silicon 的安装文件均已发布至 [v0.2.1](https://github.com/NCFXZ/VoxCue-releases/releases/tag/v0.2.1)，共享发行中使用独立平台清单，Mac 原文件保持。当前源码已上传私有 main，本机生成配置已同步；其他工作区拉取后先运行 `corepack pnpm sync:workspace` 再构建。

## 开发与启动

开发使用原生 Node.js 24 LTS 与固定 pnpm 11.25.0。先在本机平台目录安装依赖：

```sh
# Mac Apple Silicon
cd macos
COREPACK_HOME="$PWD/.tools/corepack" ELECTRON_CACHE="$PWD/.cache/electron" corepack pnpm install --frozen-lockfile
```

Windows 在 `windows` 目录执行 `corepack pnpm install --frozen-lockfile`。无需在根目录或 shared 安装依赖，已存在的另一平台依赖保留。

安装后可回到根目录执行，命令会按当前系统转发：

```sh
corepack pnpm check:workspace
corepack pnpm check:architecture
corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
corepack pnpm start
```

Windows 也可双击 `windows/Start-VoxCue.cmd` 使用现有构建，启动器不自动编译。`dev` 启动开发模式，`dev:web` 仅预览网页。模型保存在 `shared/local-models`，需要时运行 `download:speech`、`download:rag`，已有通过校验的模型不用重新下载。Mac 的 `build` 构建 Core Audio 助手、共用 Electron/Renderer 和双击入口 `macos/VoxCue.app`；`build:shared` 仍只共享编译。双击入口直接打开已有构建，不弹终端或自动编译，可固定到 Dock，须保留在 macos 文件夹内。需要 Apple Silicon、macOS 14.2+ 与 Command Line Tools；真实账户服务与真人语音质量仍需使用者验证。详见 [Mac 原生适配与启动说明](macos/docs/MACOS_PORT.md)。

Windows x64 已发布 [v0.2.1](https://github.com/NCFXZ/VoxCue-releases/releases/tag/v0.2.1) 并设为 Latest，原有更新交互和分平台选版保持。安装版自带运行库和模型，普通用户无需开发工具；本地安装包和打包暂存已按授权清理。Mac 的 DMG 首次安装与免费自动更新见 [Mac 更新说明](macos/docs/UPDATES.md)，共享流程详见[更新说明](shared/docs/UPDATES.md)。

## 数据与权限

沿用 %APPDATA%/ai-interview-copilot、既有 IndexedDB/localStorage 键，知识库/简历原件和面试记录保留。普通聊天使用独立本机数据库保存，关闭前等待写入成功，失败保留窗口；面试浮窗临时会话结束后清空，面试历史继续保留。资料提案生成时实时预览，完整生成与校验后才允许确认。凭据仅由主进程系统加密管理，令牌不进入 Renderer、localStorage 或日志；真实浏览器授权需用户亲自完成。

麦克风和系统音频必须明确开始，仅本机处理，不保存或上传原音频。启用的设备失效或权限检查失败时禁止开场；明确禁用麦克风才跳过其权限。截图保护沿用 Electron 标准接口，不保证所有捕获或共享工具都遵守。

面试回答会发送必要的本场问题、追问、面试者实际回答文字和相关资料片段；上下文在主进程内存按最近120条/约64KB限制，不混入其他场次。面试记录标题仍只使用问题，不发送麦克风回答或AI正文。

本应用用量仅统计本机收到的服务端 token 与请求次数，不代表账户剩余额度；设置提供官方用量入口。重置和删除均在原按钮二次确认，再次点击才执行，Esc、失焦或三秒后取消；不另开确认区域。
