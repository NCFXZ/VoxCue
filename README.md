# VoxCue

VoxCue 免费提供，主账号使用邮箱注册、登录和重置密码；ChatGPT 与 GitHub Copilot 在“设置 → AI 服务”中独立连接。客户端0.6.2和服务端0.5.2源码已移除支付、订单、兑换码、面试时长计费及零时长30天删云；外部AI用量由对应服务返回，优先显示5小时窗口。个人信息、面试记录和知识库分别控制云备份，默认100 MB，所有者可按用户调整容量。

云备份位于“设置 → VoxCue 账号”，底部提供删除账号。确认窗口可选保存资料，系统原生另存为选择ZIP位置；包内包含个人信息TXT、每场面试TXT/截图ZIP和各知识库原件。注销删除云端及本机资料，后台仅保留明确告知的邮箱/ID/注册与注销时间；其他设备副本和用户另存文件不受影响。退出账号仍保留本机资料。

客户端默认连接 accounts.voxcue.com.cn。[服务端0.5.2源码说明](shared/docs/SERVER_0.5.2_HANDOFF.md)包含密码8–128、独立容量和注销规则；服务端0.5.2已更新既有腾讯云部署，真实HTTPS能力和客户端连接已核对；源码提交和实际部署分别验证。用户最新要求完整功能、安全、对抗、背压和UI复验，完成后部署服务端0.5.2、发行Windows0.6.2并恢复历史草稿；在完成上线前，源码与生产状态仍分别核对。

## 开发与启动

当前Mac与Windows共用页面和内部控件；Mac保留原生红绿灯、侧栏系统材质、SF Symbols、音频/权限/凭据及更新集成，最低macOS14.2/arm64。原Liquid Glass/AppKit内容控件已移除；历史发行的系统要求只按历史理解。详见[Mac说明](macos/docs/MACOS_PORT.md)。

0.5.6 为面试回答增加与聊天一致的底部渐隐；字号仅调整对话气泡，输入框及状态文字固定。生成失败最多追加3次自动重试，手动停止/结束/关闭可取消；重试次数显示在服务名称旁，紧凑错误卡随对应回答滚动，与回答气泡共用32px连续角。技能提案的来源未核验整块提示和警告标签移除，后台来源核验/保存兼容保持；提示词未改。回归可在明确授权后校验并复制已有正式模型至临时目录，测试结束删除副本，保留原模型。完整行为、逐文件清单、Windows验证及Mac接续结果见[0.5.6交接](shared/docs/MACOS_0.5.6_HANDOFF.md)。

0.5.5 增加资料逐字段和逐条技能勾选保存，未选已有内容保持不变；多个长字段使用紧凑预览与统一阅读弹窗。完整有效提案可确认保存；来源提示以0.5.6最终规则为准，后台核验与来源元数据保持。各项显示待保存操作标签，loading 按实际字段/技能完成分别结束；仅卡片按钮执行保存，不再解析聊天文字确认。

0.5.3统一图标尺寸、同类控件的连续圆角与悬停背景，并为指定控件采用胶囊或圆形；下拉菜单保持单个展开、选中项仅尾部勾选。聊天输入区使用整列渐隐和圆形返回最新按钮，生成时显示跳动圆点；面试记录回答侧栏增加开合动画，开场摘要增加语音模型与推理设备。文本和分隔栏保留对应光标，清理失效样式，以下0.5.2的语音与回答逻辑保持。

0.5.2包含面试中语音模型/推理设备的后台切换：旧识别器继续转写，新配置就绪并等到两路语音停顿后交接，失败保留原配置；问题、草稿及去重/排队保持。回答模型和思考强度仍对下一题生效，当前回答使用原快照。800ms识别分段保留，自动回答从系统语音结束累计1800ms，不再追加终稿后1000ms等待。浮窗设置标签置于控件上方，窄屏单列；删除当前模型后切到另一已安装模型，任一语音模型就绪即可，Qwen/CPU单独显示性能提示。

0.5.0共用界面增加独立面试背景透明度和字号滑块、分层预览、不透明浮窗设置、自动应用与设备刷新、紧凑设备状态和记录知识库名称前缀；提示词沿用已确认的八组最小修改，指定主题技能允许缺少简历/JD，整套生成仍要求两者齐全。双音源时Mac/Windows分别以Core Audio/WASAPI完整系统混音为参考在本地处理麦克风回声，单音源保持原路；合成音频检查不代表真实外放和同时说话质量验收。两平台使用同一共享实现，各自原生构建与验收独立进行。

开发使用原生 Node.js 24 LTS 与固定 pnpm 11.25.0。先在本机平台目录安装依赖：

```sh
# Mac Apple Silicon
cd macos
COREPACK_HOME="$PWD/.tools/corepack" ELECTRON_CACHE="$PWD/.cache/electron" corepack pnpm install --frozen-lockfile
```

Windows 在 `windows` 目录执行 `corepack pnpm install --frozen-lockfile`。无需在根目录或 shared 安装依赖，已存在的另一平台依赖保留。

安装后可回到根目录执行，命令会按当前系统转发：

```sh
corepack pnpm check:workspace
corepack pnpm check:architecture
corepack pnpm typecheck
corepack pnpm test
corepack pnpm build
corepack pnpm start
```

Windows 也可双击 `windows/Start-VoxCue.cmd` 使用现有构建，启动器不自动编译。`dev` 启动开发模式，`dev:web` 仅预览网页。开发入口优先使用完整的 `shared/local-models`；模型缺失时在“设置 → 本地组件”下载并复用应用数据目录的缓存，也可运行 `download:speech`、`download:rag` 准备开发模型。Mac 的 `build` 构建 Core Audio 助手、共用 Electron/Renderer 和双击入口 `macos/VoxCue.app`；`build:shared` 仍只共享编译。双击入口直接打开已有构建，不弹终端或自动编译，可固定到 Dock，须保留在 macos 文件夹内。运行需要 Apple Silicon、macOS 14.2+；使用Xcode命令行工具构建必要系统助手，不再依赖macOS 26的界面SDK；真实账户服务与真人语音质量仍需使用者验证。详见 [Mac 原生适配与启动说明](macos/docs/MACOS_PORT.md)。

Windows x64 安装包从[Windows0.6.0发行页面](https://github.com/NCFXZ/VoxCue-releases/releases/tag/v0.6.0)下载，自带运行库，普通用户无需开发工具；语音和知识库模型在设置中首次下载并校验，后续升级复用同版本缓存。Windows 安装包沿用既有未配置 Authenticode 签名的发行方式；历史发行资产保持，已撤回版本不提供公开下载。正式构建入口为 windows/ 下的 package:installer，仅安装包、blockmap 和 latest.yml 用于分发，正式三项按版本保留于 windows/release/，不进入源码提交。Mac 的 DMG 首次安装与免费自动更新见 [Mac 更新说明](macos/docs/UPDATES.md)，共享流程详见[更新说明](shared/docs/UPDATES.md)。

Mac 开发宿主、启动器与正式应用复用固定本地自签名证书。0.5.5 起凭据加解密由独立固定签名助手处理，构建保留其原字节，避免应用每次升级改变助手的钥匙串身份；仅固定应用证书不足以解决历史授权。首次导入旧密码仍可能需要一次系统授权，拒绝/锁定后保留原登录文件并允许重试。现有 Sparkle 更新密钥保持。签名材料及助手规范副本必须安全备份并在清理时保留，缺失/错配即停止构建。详见[凭据与版本升级](macos/docs/CREDENTIALS.md)。

## 工作区与主线

`main` 是唯一长期开发主线；共享业务只保留一份，Windows/Mac 历史分支保留。

```text
AGENTS.md / PROGRESS.md / README.md / package.json / pnpm-workspace.yaml
windows/  专属源码、原生助手、测试源码、依赖、锁文件、构建和发行
macos/    Core Audio、权限/凭据/窗口/更新系统集成、arm64 依赖和构建
shared/   共用布局/业务/展示契约/网页回退、测试、PNG/Logo 原件及文档
```

测试结果改为零保留；本次删除 101 项可清理旧产物、4,420 个文件，仍被占用或受平台只读限制的残留见上方说明。旧报告引用不作为现存交付物。源码恢复快照与纯清理审计单独放在平台 recovery，测试源码、固定输入夹具、现用依赖/模型和真实数据保留。

平台独立安装、独立构建；测试结果不保存。共用配置在 `shared`，平台差异在各自 `package.platform.json`。Mac 对 `windows/` 只读，Windows 对 `macos/` 只读，包括脚本的间接写入。修改声明后在本平台执行根 `corepack pnpm sync:workspace`，只生成根和本平台配置，另一平台留待其本机同步。构建只输出 shared 与当前平台，格式化/图标工具同样遵守边界。Windows 生成配置现已本机同步，编译目录只包含 shared/windows。完整目录见[工作区说明](shared/docs/WORKSPACE_LAYOUT.md)。退役 benchmark 的私有输入在 `shared/benchmarks`，Windows 实测结果在 `windows/benchmarks`，不恢复实验。

## 当前功能

面试字号设置仅调整转写、问题与回答气泡中的阅读文字；输入框及其占位文字、工具栏、说话人/时间、状态和思考用时保持原字号，设置预览遵循同一规则。

面试生成失败后自动追加最多 3 次重试（最多 4 次请求），服务名称旁显示重试次数；全部失败后在对应回答下方显示紧凑警示卡、错误原因和手动重试入口，全部警告均随对应回答滚动；警示卡与回答气泡共用32px连续角。状态标签和错误卡保持固定字号，已有回答正文继续按阅读字号显示。手动停止、结束面试或关闭浮窗会取消当前请求和等待中的重试。重试沿用原问题、模型配置及原截图，不重新采集；已有正文保留到新输出到达，再替换显示。

Windows 清单 1–10 已接入当前共享界面及本机展示适配器，下文历史“待适配”由此说明取代：Windows 11 22H2+ 保持 Acrylic，使用共享 0–100 滑杆及独立面试背景偏好，旧系统保留参数并回退；应用原生主题、normal 置顶、透明留白穿透和任务栏入口隐藏/结束恢复自动生效，不改变全局设置或固定项。Windows 当前捕获方式无需单独申请，检查不截图，实际捕获仍可能失败。右上角窗口按钮有独立 no-drag 区域，浮窗拖动修正分数 DPI 的尺寸变化。完整退出重开加载新的 main/preload。

## 数据与权限

目录迁移规则只包含在当前新构建中。已发布/已安装的旧版仍使用旧路径，迁移后应使用新构建（本工作区可运行 macos/VoxCue.app），否则旧版会重新创建旧目录。

应用数据根目录为 Windows `%APPDATA%/VoxCue`、macOS `~/Library/Application Support/VoxCue`。首次运行新版会在会话创建前将旧 `ai-interview-copilot` 目录整体原子迁移，成功后旧路径消失；新旧目录均有内容或旧进程占用时停止，避免覆盖。已有 IndexedDB/localStorage 键不改，知识库/简历原件和面试记录保留。普通聊天使用独立本机数据库保存，关闭前等待写入成功，失败保留窗口；面试浮窗临时会话结束后清空，面试历史继续保留。资料提案生成时实时预览，完整生成与校验后才允许确认。凭据仅由主进程系统加密管理，令牌不进入 Renderer、localStorage 或日志；真实浏览器授权需用户亲自完成。

麦克风和系统音频必须明确开始，仅本机处理，不保存或上传原音频。启用的设备失效或权限检查失败时禁止开场；明确禁用麦克风才跳过其权限。截图保护沿用 Electron 标准接口，不保证所有捕获或共享工具都遵守。

面试回答会发送必要的本场问题、追问、面试者实际回答文字和相关资料片段；上下文在主进程内存按最近120条/约64KB限制，不混入其他场次。面试记录标题仍只使用问题，不发送麦克风回答或AI正文。

“账户与用量”显示 Copilot 官方返回的套餐、账户额度、剩余量/比例及重置时间；请求次数与 AI Credits 按官方单位分别展示，缺失或读取失败显示暂不可用，不当成0或额度耗尽。ChatGPT 登录后直接显示同一账户的额度，使用固定官方 Codex 0.164.0 的一次托管授权，不再单独连接用量；5小时和周都返回就都显示，只返回周就只显示周。旧版授权需正常重新登录一次，之后聊天、额度及续期共用；缺失/失败不填0，保留官方超链接。本应用 token 计数和本地重置按钮已从设置移除，原账本和逐回复用量保留。删除仍为原按钮二次确认，Esc、失焦或三秒后取消。
