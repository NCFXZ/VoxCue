## 共享功能：逐项核对实际运行

### 界面与品牌

- 使用当前共用PNG及已更新的windows/public/voxcue.ico，保留透明通道与原轮廓，不增加底板或圆角蒙版。侧栏Logo24px、VoxCue18px，与标题层级一致；副标题和ChatGPT可用状态行已删除，更新入口独立靠左。
- 图标随相邻字号保持正常比例和点击面积；Windows沿用Fluent，包括FontDecrease/FontIncrease、Warning及不同语义的Reset/Refresh/Update，不把字号小/大图形归一化为相同大小。检查导航、设置、设备选择、历史搜索、菜单勾选和长模型名的省略及完整提示。
- 常规按钮/设置选择框/设备选择/知识库与记录搜索保持36px规范；保留输入工具栏及独立图标按钮既有紧凑尺寸。浅深色、长文本、异常状态、最小窗口与五档DPI均不溢出、不遮挡。选择框文字/图标/数值、音频与模型设置统一对齐。
- 保留固定100%页面缩放、个人信息默认折叠与动画、弹窗编辑/保存冲突保护、可拖动分隔栏、整聊天列拖放、完整知识库上传样式及组件操作排版；不恢复已删除的外侧搜索按钮和冗余说明。资料正文/编辑12px、标题14px，思考状态沿用对应正文字号。

### 面试显示与设置

- 主设置和浮窗共用字号滑块：12–24px、默认14、步长1；背景透明度独立0–100、默认20。蓝色填充轨道、白色圆形滑块、左右语义图标与数值排列一致。
- 面试透明度与常规毛玻璃解耦，恢复源码旧版曲线：背景/工具栏取60×比例，气泡/输入取30×比例，再读取frostedProfiles分段值；不是线性alpha，也不是30/50或面板整体透明。预览包含真实工具栏、双方转写气泡、问题、回答及输入框，和实窗共用表面规则。
- 最终面试设置面板固定不透明浅/深色surface，无毛玻璃或背景滤镜；保留向下阴影、清晰透明外围。此前局部halo、整窗模糊、0–50映射和WindowMaterial专用链路均已撤销，不能在Windows恢复。
- dialog存在时禁用原生鼠标穿透。首次点击设置外但在浮窗内的转写、工具栏或按钮区域，只关闭设置并消费点击，不误触底层结束按钮或其他应用；关闭后恢复原透明留白策略。保留Windows原生normal置顶、任务栏隐藏/恢复和Acrylic平台差异。
- 无“完成”“应用音频设置”“应用模型设置”按钮，选择即保存。音频经可信重连立即生效，失败恢复最后成功选项；回答中可切模型/effort，当前回答使用原快照且不中断，下一题及等待中的后续问题使用新配置。资料/知识库仍冻结，转写/回答/截图不丢失；保留调用窗口/frame/能力校验。
- 设备列表在设置打开、恢复焦点/可见、设备通知及可见期间每5秒自动刷新；合并并发、保留选择/最后设备、错误后重试，卸载释放且忽略迟到结果。没有“刷新设备”按钮，不因枚举申请权限或启动采集。

### 音频状态、自检与恢复

- 三个紧凑状态为语音模型、麦克风、系统音频：正常勾、异常警告、加载旋转、停用/连带暂停减号。只有麦克风和系统音频显示真实输入电平；模型永无“有输入”。悬停或键盘焦点显示具体原因，正确区分音源故障、模型故障和服务故障。
- 电平使用已有activity事件，800ms短时保留/衰减、90ms平滑及160ms状态过渡，支持减少动态效果；不能用固定循环动画冒充真实音量。暂停、断流和停止清除过期活动，不新增录音或模型请求。
- 设置页麦克风测试已删除。开场权限行内保留分路10秒自检：仅点击后采集、系统/麦克风独立令牌、活动电平可见，按钮仅显示“停止”，无可见倒数和尾部“有输入/有输出”文字。自检不返回转写、不写聊天/记录，不调用AI；停止、关闭、确认、换设备、超时与取消均释放，不能抢占面试。
- 断开时原地重连/选择设备；系统音源必留，所选失效设备不能悄悄换默认或禁用。确认成功后才更新本场配置，结束/重载/迟到结果保护保持。
- 保留2200ms静音提交、仅系统终稿自动触发、麦克风不进入问题缓冲、手动草稿、排队/去重/取消/迟到保护。移除的待提交、倒计时、取消本次UI不能恢复。

- 仅图片问题保持隔离：不带普通面试历史、个人资料、自定义指令或知识库。携带文字的普通面试按已确认规则组装上下文。部分回答失败和重试位于回答气泡内；禁止恢复旧自动“发送题目时附当前截图”开关。

- 浏览器授权回调页使用共用品牌、浅深色和窄屏布局，保持PKCE/state、一次消费、Host/路径/方法校验、no-store/CSP及无外部资源/令牌。Windows原生图标用ICO，网页品牌用PNG；不改真实账户数据、DPAPI或OAuth协议，不复制Mac钥匙串证书方案。

## Windows必须补齐的原生差异

1. 当前windows/electron/speech/controller.ts尚未给shared控制器注入preprocessorFile；Mac本地AEC不能视为Windows已完成。请实现同等用户可见的本地回声处理：以所选播放设备全部应用的WASAPI系统混音为参考，仅在系统+麦克风双音源时处理麦克风，系统转写原流及单音源路径保持。不改默认设备/音量，不做按文字去重，不在系统播放时静音麦克风，UI不新增AEC开关或状态。
2. 复用shared/electron/backend/speech/preprocessor.ts的可信工厂端口及Worker握手，平台装配不接受Renderer路径。可只读参考macos/electron/speech/echoCancellation.ts；Windows/shared不得导入macos路径，不能复制第二套页面/store/业务。Windows原生时钟、WASAPI包、DSP装配应在本平台适配，共用处理逻辑按实际消费者最小复用。
3. 核实两路共同单调时钟/QPC、采样率转换、48kHz/10ms帧、参考等待上限及缺失回退、漂移/间断和真实同时说话保护；不能假设两个采集进程的独立启动时间天然对齐。检查prepare/start、暂停/重连/结束的尾段冲刷、滤波延迟补偿和Worker/utilityProcess退出，必要时接入drainBeforeRetire。错误明确停止，不静默转假成功。
4. 开发运行与临时打包布局都检查AEC JS/WASM、本机sherpa重采样和ONNX路径/许可证，不能只测API存在。Mac固定自签名、Core Audio、SF Symbols、Dock和DMG/Sparkle是平台专属；Windows使用Fluent/WASAPI/DPAPI/现有窗口与NSIS更新能力，不新增替代发行密钥或复制Mac签名材料。
5. 新Electron构建按系统临时编译/校验/备份后原地更新受管输出，保留dist-electron及子目录身份、并发锁、过期文件清理和失败回滚。验证Windows独占文件占用/部分写入失败的回滚，不使用整树删除或目录移动重建；只删除精确编号、为空、无链接且无占用的本平台空副本，不碰正常输出和未知文件。
