# macOS 1.2.3

本版以已发行 Mac 1.2.2（`ffc31e5`）为基线，共享版本源为 `shared/package.json`。Windows 原生实现保持不变；本轮共享差异核对见 [接续说明](MACOS_1.2.3_HANDOFF.md)。

## 用户可见修复

- 云端下载当前或其他知识库时，保留正在阅读的文档列表与位置；刷新期间的导入、删除和重命名保持正确归属。
- 合并云端下载与后台修复扫描对同一文档修订的索引请求，缺失或失效索引仍可恢复。
- 个人资料读取不再等待聊天恢复，冷启动时可及时显示和编辑。
- 凭据读取仅将明确损坏交给重新授权处理；系统解密和文件读取失败保留原资料并明确报错。
- 英文音频就绪与恢复提示使用完整翻译，保留用户设备原名；旧采集停止失败时显示阻止恢复的实际错误。
- 窄窗打开记录回答面板时，标题失败提示和重试按钮在可见列内换行；记录按钮、信息行和导出摘要的英文回答计数区分单复数。

Mac 已有的音频自动重连、系统代理与证书信任、AI 服务启动恢复、额度显示和生成期间查看网页来源继续沿用，不列为本版新增功能。固定凭据助手 v11、签名证书和更新公钥保持原身份，不迁移宿主真实资料。

## 验收与发行入口

使用固定 Node 24.22.1、pnpm 11.25.0 与 macOS 冻结锁，依赖仅安装在 `macos/`。更新项先执行知识库、语言和音频恢复专项，再执行完整单元、架构、功能矩阵、五档 UI、安全对抗、面试循环与音频长稳；入口见 [测试说明](../test/README.md)。

正式签名包使用独立 SIP、签名执行和 Gatekeeper 开启的 guest，固定输入与准备步骤见 [Mac guest](../../macos/docs/TEST_GUEST.md)。旧版正式 ZIP 先按固定摘要认证，再通过对应旧 ASAR 创建合成资料，并在覆盖当前 ZIP 后核对原件、索引与偏好。未修改的正式产品仅验证正常 guest profile 路径下的启动与退出，资料保留由随后独立开发宿主内的 ASAR 检查确认，不代表正式产品登录后的资料页面读取。1.1.1 的真实旧宿主 Sparkle 归档认证／准备／取消保持；1.2.2 的数据覆盖升级不代称 Sparkle 安装／重启。宿主不启动正式包，不读取真实账号、钥匙串资料或采样硬件。

向两个仓库现有 `v1.2.3` 发行追加 `VoxCue-1.2.3-arm64.dmg`、`VoxCue-1.2.3-arm64.zip`，最后上传 `latest-mac.yml`，核对齐全后设为 latest 并匿名回读摘要。保留既有 Windows 三项资产和 `v1.2.3` 标签指向；主仓在 `main` 提交 Mac 改动，以 `macos-v1.2.3` 固定 Mac 源码，发行说明链接该标签与其自动源码归档，不重复上传源码 ZIP。测试环境、VM、截图和合成资料在最后消费者退出后清理，固定身份、冻结助手和历史恢复原件不作为缓存删除。
