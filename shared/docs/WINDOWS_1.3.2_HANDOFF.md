# VoxCue Windows 1.3.0 到 1.3.2 更新与复测

以 Windows 正式源码 `v1.3.0`（`669c44a`）和对应的安装版、商店版为基线。本轮共享界面与数据逻辑由 Windows 两个渠道共同使用。原生适配和安装包须在 Windows 端同步构建和验证。账号服务使用已发布的 0.6.1。资料冲突、迁移、记录与字幕的详细操作沿用 1.3.1 逐项清单，安装及版本检查的目标改为 1.3.2。[Windows 1.3.1 逐项清单](WINDOWS_1.3.1_HANDOFF.md) · [Windows 1.3.0 基线](WINDOWS_1.3.0_HANDOFF.md)

## 新功能与改进

- 面试准备页和资料状态菜单可定位到设置中的「资料冲突」。冲突按个人资料、单场面试和整个知识库显示。可逐项选择云端或本地，也可全选其中一端。确认后回到工作界面，由资料旁的云图标报告处理进度。
- 账号资料迁移可继续清理已迁移的来源。同步重新核对资料修订和知识库成员。按修订删除面试成功后才清理专属截图，检查时仍被其他记录引用的截图保留。关闭分类同步时，挂起任务停止后续自动传输及本地写回。
- 同库恢复和导入按批发布全文索引。资料目录检查复用同一轮快照。重开应用后可继续检索保留的原件，引用应对应当前文件版本。
- ChatGPT 订阅支持 GPT-6.2 Astra 和 GPT-6.2 Sol。
- 聊天、主设置的「回答模型」和面试浮窗的「回答模型」菜单里，模型选项的高亮胶囊与底部「刷新模型列表」等宽，两端对齐。长列表滚动时刷新行留在底部。
- 聊天、面试和历史记录用透明服务商标志。长转写、长回答获得焦点后，Home 移到开头并暂停跟随，End 返回最新并恢复跟随。
- 采集时钟不可用或系统时间跳变时显示对应语言的提示。Qwen 在 CPU 上积压时，用户可切到已就绪的加速设备继续，日常切换仍等待自然停顿。Windows 复测 CUDA 路径及 WASAPI 的停止和恢复。

## 本轮发现的问题与 Windows 复测

| 场景 | 复测操作 | 预期表现 |
| --- | --- | --- |
| 模型高亮短于刷新行 | 分别打开聊天、主设置和面试浮窗的模型菜单。用短、长目录各测一次，逐行用鼠标悬停和方向键移动焦点。刷新目录并滚动到底。 | 模型行和刷新行的左右边缘一致，刷新行位置固定。浅深主题及不同缩放下，圆角和高亮均完整。旧 `interview-effort-smoke.mjs` 的侧边断言应检查胶囊边缘及滚动区是否在边框内。 |
| 同格式索引的升级 | 在 1.3.0 创建含新合成原件的知识库，索引完成后记录搜索命中与引用。升级到 1.3.2 后重新打开。 | 兼容索引继续可用，原件、引用和记录保留。再导入新文件并检索，区分升级保留与新文件建索引。 |
| 升级夹具误用旧快捷键数量 | 在正式 1.3.0 中自定义窗口和快捷键帮助按键，再升级到 1.3.2。在验收夹具中按来源版本核对实际快捷键集合。 | 已支持的快捷键及自定义绑定升级后保留。更旧版本缺失的帮助快捷键使用默认值，覆盖升级不重置已设置的按键。 |
| 升级夹具误判旧资料归属 | 用全新安装的 1.3.0 创建合成账号资料，再覆盖升级。另用含未归属资料的旧版基线核对迁移。 | 1.3.0 中已归属账号的资料继续使用原账号分区，旧资料迁移标记保持无归属。早期未归属资料仍由首个实际接管它的账号领取。 |
| 并行推理干扰切换专项 | Windows 端独占本机推理资源，以合成双路音频依次切换 CPU、CUDA 和轻量识别，另测候选加载失败与取消。Mac 并行跑客机推理时曾触发积压上限，改为串行复测。 | 常规切换保持采集，交接事件和转写归属正确。取消和候选失败保留原配置，退出后释放识别进程。达到积压上限时仍明确报告受影响的转写。 |
| Codex 模型目录 | 在隔离目录中连接可用的测试订阅，打开并刷新模型菜单。分别检查订阅目录与 API 密钥目录。 | 订阅使用实际随包 Codex 版本请求目录，并按可见性、可用性和最低客户端版本显示。Windows 与 macOS 1.3.2 均固定 Codex 0.171.0。 |

## Windows 发版前验证

- 在 Windows 上运行 `pnpm sync:workspace`，核对根清单和 Windows 应用均为 1.3.2。Microsoft Store 使用独立递增的包版本。安装版用原更新身份，从 1.3.0 测试升级和重启，并用干净环境走一次全新安装。测试缺少资产、校验失败、离线重试和正常退出。[Windows 构建与升级入口](../../windows/package.platform.json)
- 用合成账号复测原生 API 密钥输入、遮挡和显示，补测账号切换、旧资料恢复和资料冲突选择。通过 Windows TLS 预配配置隔离证书，再检查手机连接、重连和撤销授权。[Windows 平台对齐项](WINDOWS_1.3.1_HANDOFF.md#windows-原生适配和发行验收)
- 以 100%、125%、150%、175%、200% 五档核对英文和中文的模型菜单、标题、滚动条及操作按钮。用合成音频验证双路采集、静音、设备切换、中文和英文恢复提示、录音回放及退出收尾。[共享测试入口](../test/README.md)
- RAG 用本轮新建的 TXT、Markdown、PDF、DOC、DOCX 测试导入、建索引、检索、引用、替换和删除。保持现行模型与检索参数，跳过旧准确率数据集。[RAG 功能与索引](RAG_ARCHITECTURE.md)
