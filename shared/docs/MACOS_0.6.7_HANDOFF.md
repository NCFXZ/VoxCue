# Mac 0.6.6 → 0.6.7 逐项更新与验收

## 基线和执行边界

- 本轮以 Windows 当前 UI/功能为准，合并远端 `f13c5e1`。保留 Mac 0.6.6 提交 `ff2fea7` 的工具栏自然高度、键盘回顶和原生截图测试保护；不是用旧 Windows 文件覆盖整个远端。
- 版本唯一来源为 `shared/package.json` 的 **0.6.7**。Windows 只生成根及 Windows 清单；`macos/` 未新增本机修改。Mac 拉取后先检查 status/diff，保留本机后续工作，再运行 `node shared/scripts/sync-platform-manifests.mjs`，在 `macos/` 执行 `pnpm install` 更新自己的锁；禁止复制 Windows 锁或修改 Windows 树。
- 本交接覆盖共享产品变化及 Mac 本机待验项，不保存测试成绩。逐项输出“通过 / 修复后通过 / 待验 / 不适用”、失败原因和复测入口到终端/对话。Windows 的合成测试不代表 Mac、真实账户、物理麦克风/系统回环、权限撤销或真实模型语义已经通过。
- 默认窗口大小、中文 UI、资料兼容和确认保存规则保持。英文可局部加宽控件，但必须视觉对齐。不要恢复联网开关、聊天内引导卡、旧技能补摘要提示卡或 token 计数行。
- 仅源码交付；不自动签名、发行 DMG、修改 Latest 或部署官网/服务端。0.6.6 正式安装资产、恢复目录、签名和凭据身份继续保护。

## Mac 建议执行顺序

1. 核对 Git 及 `AGENTS.md`，同步本平台清单/依赖；保留 Mac 固定签名身份，Windows 全树只读。`pnpm check:workspace` 的 Windows 漂移只读报告，不在 Mac 生成它。
2. 在 `macos/` 执行 `pnpm typecheck`、`pnpm check:architecture`、`pnpm test`、`pnpm build`、`pnpm audit --audit-level=low`。保留安全断言；沙箱权限导致的失败需区分环境后原样复测。
3. 解锁的 owner 控制台串行执行 `node ../shared/test/scripts/functional-suite.mjs`，包含 600 秒真实公开音频 ASR 长稳、20 轮面试循环、安全/对抗、界面与账号协议；普通夹具不得调用正式凭据助手。
4. 执行 Mac 原生矩阵及 `ui-refinement-matrix.mjs` 五档缩放，补入 language/preparation-guide。重点按 M001–M052 逐项人工/自动核对；预览触控板惯性、材质边缘、原生弹窗、锁屏取消和辅助功能均须本机确认。
5. 定向入口：`language-smoke.mjs`、`preparation-guide-smoke.mjs`、`typography-smoke.mjs`（聊天/面试公式、离线字体和长公式内部滚动）、`interview-typography-smoke.mjs`、`interview-chrome-smoke.mjs`、`interview-motion-smoke.mjs`、`chat-progress-smoke.mjs`、`profile-ui-smoke.mjs`、`profile-selection-smoke.mjs`。公式、意图、提案、语言、滚动对应 `markdown`、`rag`、`profile-proposal`、`profile-store`、`ui-language`、`preview-scroll` 单测。
