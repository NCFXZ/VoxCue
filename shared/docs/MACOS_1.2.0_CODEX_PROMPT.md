# 交给 Mac Codex 的接续提示词

请在 Mac 本机接续 VoxCue 1.2.0。先核对当前 main、status／diff 和根 AGENTS.md、PROGRESS.md，保留已有工作，然后完整阅读这两份文件：

1. `shared/docs/MACOS_1.2.0_HANDOFF.md`：1.1.1 → 1.2.0 的逐条修改，包括本轮 Windows 测试发现的修复，以及每项对 Mac 的影响和回归点。
2. `shared/docs/MACOS_1.2.0_TODO.md`：Mac 专属修复、需先验证再决定的事项、共享改动的 Mac 本机验收和最终包门禁。

开始前核对 Windows 发行执行者在最终包验收后交付的冻结 main 提交号；交接中的 1.1.1 提交只是本轮审阅输入，不能当作已包含 1.2.0 修复的接续输出。

请按编号逐条核对源码和真实消费者：共享 S01–S54 复用已有实现，不复制到 Mac，W01–W22 仅作 Windows 参考；Mac 专属已确认且值得修复的事项以最小改动实施；仅凭静态推断的项目先在允许的隔离条件下验证，再决定是否修改。先收尾 M4 正式包测试隔离，再启用 M1 fuses／Hardened Runtime，联动封闭实际支持的 renderer CDP port／pipe 启动路径并迁移原测试入口，不运行会触及真实资料的历史正式包测试。

本机同步版本与配置，补齐同版本依赖、原生构建、截图 Worker／unpack、签名与更新资源闭包。逐项执行相关回归，再执行完整架构、类型、单测、安全／对抗、稳定性、英文翻译、浅深主题／视觉对齐和最终隔离包测试；发现问题修复后重测。不能用 Windows 成绩代替 Mac 原生、权限、Keychain、签名和最终包结果。

`windows/` 全树只读。保护固定签名身份、私钥、原件、真实账号／Keychain、现用模型和恢复基线；不轮换身份、不升级 SDK／模型、不迁移或静默删除历史资料。GUI／原生／推理仅在 owner 已登录解锁的控制台串行执行，只用自有临时合成资料和摘要认证公共模型／音频，不采样真实硬件或宿主屏幕，不修改系统权限。成绩只在终端／对话，结束清理本轮自有临时产物。

保留用户已决定不改的 Qwen CPU 长段算法、积压与手动恢复策略、第三方网站图标、单份简历语义及两份交接中列出的其他边界；除修复确认问题所必需的最小改动外，不改已验收 UI。

持续更新 PROGRESS.md 的接续摘要和待办；完成后按编号说明已实施／已验证／仍未验证、发现的新问题及处理、实际测试范围和剩余限制。缺少设备、身份或安全隔离时明确指出，不跳过断言或伪称通过。此次接续不要自行提交、推送或发布 Mac 版本；待逐项验收后再由用户决定发行。
