# 共用桌面界面（2026-10-25）

Mac 与 Windows 直接编译 `shared/src` 的同一份 React 界面。内部按钮、菜单、材质、表单、进度条、布局和无障碍语义共用。唯一图标例外：Mac使用SF Symbols，Windows使用Fluent，不恢复平台页面或内容控件。

最新材质统一：用户明确选择聊天输入框的网页毛玻璃，Mac/Windows同步，侧边栏保留现有系统材质。侧边栏之外的品牌胶囊、标题、输入框、返回最新、阅读气泡、下拉菜单、状态提示及截图查看控件，统一使用 `--web-material-fill` 与 `--web-material-filter`（blur 24px、saturate 125%）。不叠加局部系统玻璃；本轮WindowBackdrop绑定、几何IPC、构建/打包和测试已移除，Windows无需实现局部原生模糊。网页滤镜处理同窗口内的文字、图片等内容，不能模糊窗口外的应用。

顶部品牌胶囊叠加气泡填充与面板底色，使独立于主面板的胶囊也匹配文字气泡的最终透明度；收起时保留同一效果，减少透明度时使用实心底色。

最新局部配色：面试两个标题及输入框使用同一24px滤镜，但深色底色及其防重影底层混入10%白色，降低黑色厚重感；浅色及无障碍实心底色保持。查看器两侧箭头与页码胶囊不再显示描边，保留尺寸和键盘焦点。

个人信息与面试记录AI回答的固定标题复用聊天顶部的同一材质和24px内容覆盖渐显规则。标题高度由ResizeObserver测量，正文滚动区延伸到标题后方，同时保留首行留白和定位避让；浅深色、面板重新展开及窄窗口均使用共用实现。

面试两块大背景保留原透明透视底色，不套整窗模糊。标题仅随正文滚入渐显聊天同款材质，不裁掉顶部正文；回答从输入区后滚到面板底部，仅最后36px渐出。返回最新是输入框外的同级独立控件，复用聊天材质/阴影，不再在正文上挖圆形遮罩。透明窗口的固定标题、输入区和箭头下方局部补齐聊天页面底色，再由其上层24px背景滤镜模糊滚动文字/图像，避免透明合成保留清晰重影；大背景和间隙保持原透视。末行和动态输入区仍保留阅读避让。减少透明度、高对比度和强制颜色模式保持实心保护。记录搜索清除为28px圆形点击区域、14px平台图标，常态无底板，悬停/聚焦显示中性底板；清除后焦点返回搜索框。

整组面板220ms上移淡出、280ms进入；单独转写左移淡出/进入，回答240ms平移居中/让位。退出后缩原生窗口、进入前扩展，保留草稿和隐藏转写的阅读位置，防止重入并尊重减少动态效果。动画沿用连续圆角与阴影。

面试输入框默认一行，外部上下内边距10px/8px；多行自动增高至六行后内部滚动，清空收回。共用输入测量支持独立行数范围，聊天仍保持默认两行至十一行。发送/截图按钮尺寸、材质和底部渐出不变，底层与箭头随输入高度更新。

内部控件采用共用胶囊/圆形，菜单是Radix、中性灰高亮。Mac使用SF Symbols、Windows使用Fluent；编辑/删除/确认逻辑、图标尺寸和键盘行为共用。输入框40px连续轮廓；截图禁用翻页仅淡化箭头，保留玻璃底板。面试设置与图片弹层外侧保持透明，普通模态遮罩保持原有压暗规则，不新增玻璃。

已移除 Mac Liquid Glass、AppKit 内容控件、原生下拉菜单、独立输入框/返回按钮前景窗口、几何投影 IPC、裁切同步以及专属测试探针。旧方形按钮/菜单圆角声明也已替换为共用样式。历史原生展示的截图或测试结果不能作为当前界面验收。

Mac主窗口和登录窗口保留系统原生红绿灯、隐藏标题栏与系统圆角，内部控件继续共用；shared按平台身份预留红绿灯空间，不在Mac绘制Windows式窗口操作。面试浮窗保持无边框工具栏。

`shared/electron/presentation.ts` 仅保留窗口生命周期的类型端口。Mac 通过 Electron 处理主题、Dock、窗口置顶、全屏工作区与透明区域鼠标穿透；Windows 保留其 HWND 策略。系统音频、屏幕权限、凭据加密、文件对话框、系统菜单栏快捷键及更新仍属于系统集成，不能因删除界面适配而破坏。

Mac 构建与新包最低系统为 **macOS 14.2，Apple Silicon**，由现有 Core Audio 进程音频 Tap 与固定运行时的基线决定。已发布的 macOS 26+ 安装包和签名清单保持原样；源码改动不代表旧发行包已获得兼容。当前机器不能代替 macOS 14.2/15 的实机验收。

两端各自在本机执行配置同步、类型/架构检查、构建、单元和 `functional-suite.mjs` 全套共用界面检查。Mac 追加系统集成与100/125/150/175/200%界面矩阵；Windows 的实际 DPI、窗口及原生系统集成仍需 Windows 本机。GUI 串行，仅使用隔离合成账户、资料、图片/音频和固定公开临时模型，退出清理。Windows 专属目录在 Mac 只读，模型、索引、依赖锁及签名身份保持；版本以 `shared/package.json` 为准，在对应平台生成配置。

0.5.10发行前修正了只读面试预览的局部底色：预览在自己的浅深色作用域重新解析标题/输入框材质，与实际面试逐层一致，减少透明度仍为实心。所有现有圆形/胶囊切换控件共用220ms ease、整组交叉淡化及3px位移参数，固定圆弧端帽且无可见按钮描边；原触发、二次确认、超时与禁用逻辑保持。

Mac图标由SymbolBuilder在构建时通过公开AppKit API生成192px透明资源，随Mac包分发；运行时使用共享SVG尺寸、currentColor和无障碍接口，无需Liquid Glass或macOS26。build:shared及Mac开发入口准备资源，Vite仅替换公共图标模块。品牌Logo独立保留。

2026-10-25最终参数按Liquid Glass适配前的滑块映射：聊天100%、面试100%。面试大背景100映射完整曲线60%；内部玻璃已统一聊天公式（0.6+底色曲线×0.4），不再采用独立阅读层底色。Mac主窗恢复Electron sidebar vibrancy/followWindow并保持网页底板透明，100档透出系统毛玻璃；不使用Liquid Glass或AppKit内容控件。用户已确认两端共用参数，Windows随后本机调整。
