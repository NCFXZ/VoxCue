# VoxCue 0.6.2 → 0.6.3：Windows客户端逐项交接

客户端基线：`8eb42a79fe804531f010749ff46635bf320f5308`（Mac 0.6.2最后修复）。本版本产品源码快照和Mac资产见[发行记录](MACOS_0.6.3_RELEASE.md)，文件级范围见[逐文件审计](CLIENT_0.6.3_FILE_AUDIT.md)。配套[Windows Codex提示词](WINDOWS_0.6.3_CODEX_PROMPT.md)及[服务端接续](SERVER_FOR_CLIENT_0.6.3_HANDOFF.md)。旧版交接只作历史，不恢复已撤回功能。

## 范围与基线

- shared中的页面、状态、IPC、存储与统计同时覆盖Windows/Mac。此轮在Mac完成本机验证；Windows原生、五档DPI、NSIS安装/更新仍须Windows实际验收，不能用Mac成绩代替。
- 版本唯一来源`shared/package.json=0.6.3`。根与Mac清单已生成；Windows清单在Mac只读，接续先在Windows运行`node shared/scripts/sync-platform-manifests.mjs`，只生成根/Windows，不手改或复制Mac锁。
- 依赖/锁、SDK1.0.21、Codex0.164.0、模型/索引/RAG v7、host-id、代码/凭据助手/Ed25519更新身份保持。Mac最低14.2/arm64；Windows x64。macos全树在Windows只读。
- 本轮Mac不修改服务端。固定0.5.2参考`472541cc80c77439f02c45d0bf0aed913b036134`；本机shared/server旧参考没有被替换。Windows后续的新服务端任务按独立交接实施，不能把它记作此版Mac已完成的后端功能。
- 发布沿用私有`NCFXZ/VoxCue/main`及公开`NCFXZ/VoxCue-releases/v0.6.3`；先验包再上传，不替换真实安装。现有Latest v0.6.2、旧版本、Windows旧资产和models-v1.0.0保持。
