# VoxCue 1.3.6

## 中文

- 新增 Kimi 和 Gemini API 支持，可用于面试准备和面试回答。
- 优化界面动画。
- 优化聊天与面试布局。
- 改进资料更新提案的生成与异常恢复，提高生成可靠性。
- 修复添加或更换 API 密钥时输入框闪烁的问题。

## English

- Added Kimi and Gemini API support for interview preparation and answers.
- Improved interface animations.
- Improved chat and interview layouts.
- Improved generation and error recovery for profile update proposals to make generation more reliable.
- Fixed input field flickering when adding or replacing an API key.
