## 产品变化与修复

- 私人局域网 HTTP + WS 扫码配对，短时邀请、电脑核码审批、单设备授权、断线恢复、会话版本与请求去重；网络仅接受白名单操作，不暴露 DesktopAPI、凭据或任意文件。
- 移动页面随应用打包，只提供移动 manifest 依赖闭包；支持转录显隐、问答气泡、LaTeX MathML、共享草稿、发送／停止、麦克风与自动回答。电脑草稿为准，重连不重放离线操作。
- 仅转录和远程面试的输入状态独立管理，麦克风／系统音频开关保持现有识别连接；音频静音断句、迟到结果、输入切换和取消使用实际 ACK 及归属保护。
- 可编辑快捷键，实时键位预览、组合规则、清空与恢复默认、冲突拒绝与继续录入；单项不可用不阻止面试。整窗隐藏时本场全局快捷键继续执行，包括截图，保持隐藏且不抢焦点；既有忙锁、组字和最多五张限制保持。
- 隐藏布局动画使用主进程确认的可见状态，不依赖 Chromium 的可见性报告；动画进行中隐藏有有界取消保护。场内设置同时受原生视口与逻辑画布限制，窄窗口关闭按钮保持可见。
- Windows截图改用工具栏中心与本机DPI选择显示器，避免透明预留画布在相邻大屏上占比更高时选错屏幕；仅传自有窗口句柄，原输出／超时／取消限制保持。
- 整理面试设置、开场摘要、设备徽标、输入控件和中英文布局；保留角色副标题，恢复历史阅读位置，完善组件下载取消延迟。
- 删除经消费者核对的旧确认重置封装、图标、文案、固定截图宽度，以及已撤回功能的独占旧脚本／夹具；不删除现用模型、原件、凭据、历史发行或恢复文件。
- 验证维护同步现行尺寸／导航／角色和独立布局；IPC 条件实际等待异步结果，设置往返等待退出视觉结束，合成语音端口使用完整输入状态 ACK。保留原严格交互、几何、安全与生命周期断言。
- 最终ASAR检查发现并补齐显式打包器遗漏的`ws`运行依赖，两个渠道重建；增加包内实际LAN服务与资源访问验证，不以开发node_modules或manifest存在代替运行。
