## 3. 客户端需要消费的契约

| 端口或数据 | 0.5.2契约 | Mac客户端验证边界 |
| --- | --- | --- |
| 账号注册/密码重置 | 普通密码NFC8–128码点；挑战、重发、弱密码与账号安全保护保持 | 两处提示“不少于8个字符”；128 emoji不被HTML maxlength=128误截断；实际错误/忙碌/取消和迟到结果处理 |
| 管理员密码 | 仍15–128，与普通用户不同 | 客户端不修改后台规则；不要按新普通规则改后端或管理员 |
| 备份空间 | 服务端返回当前容量和分类用量，默认通常100 MB，自定义值可变化 | 容量条/图例十进制MB、无原生title、aria-label保持，不能写死100 MB |
| 空间管理操作 | owner账号详情account.storage；原因/确认/fresh TOTP/CSRF/幂等/审计 | 作为后台已完成功能理解；Mac客户端不创建或测试真实管理员操作 |
| 删除能力 | capabilities.accountDeletion等于account-erasure-v1 | 缺能力不套用旧注销端口；免费化不删主账号认证 |
| 用户主动删除 | POST /v1/account/delete，当前密码及confirm:'DELETE'；当前会话绑定用户，不能传任意目标账号 | 使用固定参考+owner合成用户联调；错误密码不登出，真正会话失效按原流程清理 |
| 删除结果 | deleted:true、cloudCleanup:'queued'；云元信息删除、密文有界GC | 提示资料/本机/云端后果，不能宣称灾备/其他设备/外部AI账户即时删除 |
| 最少注销记录 | 独立closed_accounts仅id/email/created_at/deleted_at，后台“已注销” | 用户确认提示准确；同邮箱新账号不继承旧资料，已注销状态不可恢复 |
| 已撤接口 | 支付/订单/退款/兑换/赠时/面试计费/租约无运行路由 | 已认证合成旧请求404；未认证请求可先401，不为追求404放宽认证，不对生产发写入探测 |
| 定期维护 | 不因零时长30天清云；上传24小时过期和用户主动删除GC保持 | 免费面试不依赖时长租约，也不能移除云容量/全局安全限额 |

保存资料和本机删除属于客户端：系统另存为，三个根目录个人信息/面试记录/知识库；取消/失败不删除，未完整恢复的云项不能静默漏导。已绑定AI外部账号不会被注销接口删除；客户端清本机授权及个人缓存，不删除公用模型、主机/更新身份。具体归档上限、分块和中断清理见客户端C034–C039/C044/C050。
