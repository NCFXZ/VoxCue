## 隔离执行

将受控源码复制到带owner标记的临时目录，TEMP/TMP/TMPDIR、profile、数据库、密钥、构建和截图均在owner根中；只开放自有loopback和内存邮件。禁止读取真实.env或账户/数据库。运行scripts/typecheck.mjs、scripts/typecheck-admin.mjs、scripts/build-admin.mjs和test/admin-qr-smoke.mjs。

受影响定向文件：accounts、password-policy、account-deletion、storage-limits、admin、admin-pressure、free-service、monitor、cloud-http、backups、adversarial、sync、recovery、operations。保留原安全、背压、路径、并发和拒绝断言；Windows的Linux专属symlink权限项单列，不伪称通过。最新范围不执行默认全部test、cos-pressure或原1800秒soak；长稳本身的角色、时长、RSS与限流约束不改。

后台实际UI夹具test/admin-storage-ui-smoke.mjs使用当前客户端固定Electron/Playwright作为宿主，VOXCUE_CLIENT_ROOT为客户端绝对路径；覆盖三角色容量、恢复默认及邮箱/已注销详情。五档DPI按新授权或受影响目视范围串行补验，截图仅临时目录，目视后清理。

## 客户端和部署边界

客户端版本0.6.2，普通密码两提示“不少于8个字符”，原始HTML maxlength1024保留以支持128个emoji。账号页包含容量、三个同步开关、右侧同步/刷新，删除入口在备份下方。

注销弹窗可选保存资料，系统原生另存为ZIP，三根目录分别个人信息TXT、每场面试TXT及截图ZIP、各库原件。取消/失败不删除；未恢复云项需先完成恢复。注销后本机资料清空、公用模型和固定身份保留；后台最少注销记录明确告知。其他设备已下载副本、用户另存文件和离线灾备不属即时清理范围。

shared/server/只是被忽略测试参考，不进入客户端Git或包；先从独立仓库获取源码再同步受控参考，禁止复制锁/产物/真实配置。线上0.5.1在另行部署前保持原行为。本次只上传审计源码，不发行、不改Latest或真实安装，不自动部署0.5.2。
