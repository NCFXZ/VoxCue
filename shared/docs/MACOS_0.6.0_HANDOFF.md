# VoxCue 0.5.11 → 0.6.0：客户端完整更新与 Mac 接续

日期：2026-10-27。本文只描述**客户端**，服务端现状另见 [服务端只读参考](SERVER_0.5.1_REFERENCE.md)。配套 [逐文件/逐差异块审计](CLIENT_0.6.0_FILE_AUDIT.md)、[Mac Codex 提示词](MACOS_0.6.0_CODEX_PROMPT.md)。

## 1. 版本、仓库和禁止改动的范围

- 客户端仓库：`NCFXZ/VoxCue`，目标版本 `0.6.0`，版本唯一源 `shared/package.json`。
- Windows 0.5.11 基线：`0c86881c732e87f80bade27e055da950b672914b`。
- **Mac 开发者的差异基线**：`2af9c78c3e05b3daf303130c3e6dace61ab5734f`。这是远端已经完成的 Mac 0.5.11 续期验证、SF Symbols loading 修复及交接提交；本轮先快进保留它，再恢复并整合 0.6.0。不要撤回其 loading、停滞代理保护或历史验收。
- 服务端独立仓库：`NCFXZ/VoxCue-server`，只读固定提交 `43b6a973849bdc3c204d8434a21857b943048758`，版本 **0.5.1**，不是客户端的 0.6.0。115 项远端受控文件与当前本地副本逐文件一致（允许工作区 CRLF/LF 差异）。
- **禁止修改服务端代码、配置、依赖锁、数据库结构、生产数据、Docker/Nginx/systemd、邮件/DNS、后台管理员及云权限；禁止部署或重启生产服务。**发现接口适配问题，只改客户端契约、主进程、业务状态、Mac 承载或客户端测试。
- `shared/server/` 是客户端集成测试使用的独立只读副本，已从客户端 Git 上传范围排除。不要把它加入客户端提交，不需要为 Mac 另建服务器。
- 共用展示/契约/业务仍在 `shared/`；Mac 只做必要系统集成和 SF Symbols，保留原生红绿灯。Windows 专属源码、Windows 锁和安装器在 Mac 只读。
- 支付保持关闭。保留固定 Copilot SDK/平台运行时 `1.0.21`、Codex `0.164.0`、RAG v7、原模型/索引、签名证书、凭据助手身份、Sparkle Ed25519 及 macOS 14.2/Apple Silicon 基线。
- 本次上传的是源码、测试、配置和文档；不授权发布 0.6.0 安装包、改 Latest、覆盖已有发行或替换真实安装。

## 2. 阅读与验收方法

下列 **C001–C140 每项都必须单独回填**：`通过 / 修复后通过 / 阻塞待验 / 不适用`、实际命令或操作、观察证据、修复文件、复测结果、未覆盖边界。不得用“同 Windows”“应该可以”“编译成功”替代 Mac 验证。文件审计还列出全部改动文件和每个 diff hunk 的位置；功能表和文件表一起核对，不能只挑新界面测试。

所有 GUI/原生检查串行，只用自有临时 profile、合成账号/资料/图片/邮件端口及固定公开临时音频/模型。不得读取真实 Keychain 资料、真实账号/原件、正式模型库或采样物理音频。需要真实账号或硬件的事项单列，不擅自使用。结果到终端/对话，临时数据库、模型、截图和副本退出清理。
