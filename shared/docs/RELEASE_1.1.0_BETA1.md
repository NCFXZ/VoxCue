# VoxCue 1.0.2 → 1.1.0 beta 1 更新与修改清单

整理日期：2026-11-09。

本清单以已发布的 1.0.2 为基线，按当前工作区的最终实现逐条整理。`1.1.0 beta 1` 是本次清单的目标版本名称；当前应用版本号仍为 `1.0.2`，本次整理没有修改版本号、生成安装包或发布新版。代码核对基线为 `a8357b2`，包含已合入的 Windows 与 Mac 1.0.2 工作。

共享界面与业务逻辑位于共用实现中；Windows 原生窗口调整单独标明。本轮没有修改 `macos/`，不将 Windows 原生验证视为 Mac 已完成适配。

## 一、面试方式与“仅转录”

1. 新增“远程面试／仅转录”两种面试方式，替代本轮试作后撤回的“面对面”方案。
2. 主设置、开始面试弹窗和面试中的设置共用同一面试方式控件，名称、选中状态与交互保持一致。
3. “仅转录”只使用麦克风作为问题输入，不采集系统音频；开始面试时只检查麦克风权限和设备，不请求系统音频权限。
4. 主设置和面试中设置在“仅转录”下禁用系统音频下拉框，直接在框内显示“设置为‘仅转录’时不可用”的原因，不再额外占用一行副标题。
5. 禁用系统音频下拉框时保留标题的正常颜色；框内提示与普通下拉框使用相同字号，中英文可按空间换行。
6. 面试方式偏好单独保存；切换到“仅转录”不会覆盖原先保存的远程播放设备、麦克风设备及远程麦克风启用偏好。
7. “仅转录”的转写消息显示来源“麦克风”，不再将其标为面试官，也不显示远程模式的左右角色说明。
8. 麦克风识别内容可实时进入问题草稿，终稿沿用去重、手动编辑、Enter 发送和忙时排队等既有流程；关闭自动回答后仍可手动发送。
9. “仅转录”接入原有自动回答规则：根据已处理的问题来源音频计算 1800ms 静音截止点，识别耗时计入其中，不在终稿到达后再额外等待一轮。该规则在 1.0.2 已存在，本版扩展到麦克风问题来源。
10. “仅转录”麦克风文本进入问题上下文，不误作用户已经说出的个人回答或个人经历事实；底层仍保留真实的麦克风来源。
11. 面试中支持实时切换“远程面试／仅转录”。切换后保留已产生的转写和回答，重置旧问题来源的缓冲与自动发送边界，后续发言按新方式处理。
12. 运行中切回远程面试前检查所需的系统音频；首次启用尚未检查的麦克风时完成预检，同一设备后续软静音切换不重复探测。

## 二、面试快捷键与帮助窗口

13. 新增全局 `Ctrl+H`：隐藏或恢复整个面试界面，包括顶部胶囊及已打开的快捷键帮助窗口。
14. 新增全局 `Ctrl+F`：收起或展开面试内容区域，并保留转写面板原先的开合偏好；原本已收起转写时只收放回答区域。
15. 新增全局 `Ctrl+T`：独立显示或隐藏转写区域，不强制展开已收起的整个面试内容区域。
16. 新增全局 `Ctrl+M`：切换麦克风输入的软静音；整个面试界面隐藏时仍可操作。
17. `Ctrl+M` 不再通过暂停、断开或重新连接音频实现；保留已建立的麦克风连接及识别服务，远程系统音频继续转写。
18. 修复等待麦克风切换确认时误拦系统音频事件的问题，系统终稿和处理进度继续送达；只隔离正在变化的麦克风通道。
19. 在回答区顶部的“转写”旁新增“快捷键”开关，两者使用一致的胶囊边框、开关圆点、字号、图标尺寸和高度。
20. 新增独立的快捷键帮助窗口，开场默认显示，固定在当前面试所在屏幕的工作区左下角，而不是面试面板左下角。
21. 快捷键帮助列出收放面试、收放转写、整窗显隐、麦克风软静音及既有截图快捷键；Windows 截图仍为 `Alt+S`，不将其重复计为新增快捷键。
22. 快捷键帮助与转写使用相同材质和透明度偏好，随透明度滑块变化；可通过开关、关闭按钮或 Escape 关闭，结束面试时一并销毁。
23. 快捷键按本场面试注册和释放；注册冲突时回收本场已取得的按键，结束、加载失败或窗口销毁后释放，避免留下全局按键占用。

## 三、悬浮窗显示、收放与缩放

24. 面试悬浮窗默认靠近屏幕工作区顶部显示，减少开场位于屏幕中央的遮挡。
25. 面试主窗口和快捷键帮助共用 160ms 显隐渐变；快速反向操作从当前透明度衔接，支持系统“减少动态效果”。此动画不改变用户设置的内容材质透明度。
26. 修复面试窗口出现时的空白、闪烁和位置抽动：等待原生窗口加载与当前页面布局都就绪后再显示。
27. 修复快速收起、展开、转写开合和重复点击引起的状态不同步；动画期间串行处理布局操作，迟到的旧结果不覆盖新状态。
28. Windows 面试窗口改为预留透明原生画布，面板收放和尺寸调整主要更新可视布局，避免反复改变原生窗口边界带来的瞬时闪烁和位移。
29. 修复大范围调整面试面板尺寸时顶部胶囊中途移动、结束后才回到原位的问题，操作期间保持胶囊的屏幕锚点。
30. Windows 拖动与缩放共用一次带 DPI 补偿的边界更新，减少非整数缩放下二次尺寸校正产生的偏移。
31. 修复缩放手柄跑到透明大画布或屏幕边缘的问题，手柄以实际可见面板的底角为边界。
32. 设置背景的鼠标拦截范围、缩放命中和状态提示位置与可视面板对应，保留拖动滑块时的连续交互。
33. 修复关闭设置后顶部胶囊短暂消失的问题，设置开关沿用稳定画布与显示就绪流程。
34. 加强窗口失败回收与页面代次检查：旧页面的迟到就绪通知不能唤起新页面；加载失败或初始化中关闭时清理关联窗口和监听。

## 四、面试设置布局与控件

35. 悬浮窗收起时也能完整打开面试设置，不再只露出标题或被收起高度裁掉。
36. 收起状态打开设置统一采用最小的仅回答画布尺寸，不受转写区域原先开合状态影响；关闭设置后恢复收起状态，并保留原展开尺寸和转写偏好。
37. 面试设置右侧选项靠右对齐，沿用约 240px 的控件宽度上限，窄窗最多占内容区 60%，避免宽窗中下拉框过长，同时给长名称保留空间。
38. 主设置音频设备移除原有音频图标，改以“系统音频／麦克风”为主标题，“面试官／面试者”为次标题。
39. 面试中设置的系统设备标题简化为“系统声音”，删除后面的“播放设备”字样。
40. 面试方式统一采用完整圆角胶囊；控件整体高度与下拉框一致，英文名称不会因为换行把切换按钮撑高。
41. 胶囊选中滑块使用平滑过渡；下方内容使用统一的高度展开、收起动画，保持外框和其他内容稳定。
42. 主设置、开始面试和面试中设置复用同一高度过渡逻辑；快速反向切换、尺寸变化、关闭窗口及减少动态效果时正确取消动画。

## 五、开始面试弹窗

43. 重新整理开场摘要，从分散的双列信息改为统一的标题—值清单，并按知识库与用量、音频设备、模型配置分组。
44. 摘要中的设备标签改为“系统音频 · 面试官”和“麦克风 · 面试者”，与设置中的主次顺序一致。
45. “仅转录”开场摘要直接移除系统音频行，设备与权限中也不再显示系统音频项目，不保留无用的禁用占位行。
46. 思考强度跟在回答模型名称后，推理设备跟在语音模型名称后，使用主题色显示参数，删除重复的“思考强度／推理设备”文字。
47. 两种面试方式使用统一的弹窗外框高度；切换摘要和权限内容时外框不再突然变高或变矮。
48. 统一首次打开和再次打开时的标题分割线、预检占位和信息结构；预检结果带请求代次，旧方式的设备结果不能写回当前方式。
49. 隐私说明及“取消／确认开始”固定在弹窗底部，中间内容独立滚动；内容较少时按钮不再向上漂、在底部留下大块空白。
50. 缩短隐私说明为“音频本机处理，不保存。回答资料发至对应服务”，减少重复文字；仅在实际启用回答服务时追加对应接收方。
51. 修复切换弹窗内容时过渡快照越过滚动区域、标题或圆角边界的问题，动画按实际可视范围裁剪。
52. 关闭内层对话框时阻止 Escape 取消事件继续传播，避免同时触发其他窗口操作；停止音频测试失败时也检查请求代次，避免旧错误显示到新检查中。

## 六、记录、按钮与侧栏细节

53. 面试记录进入详情前记住列表滚动位置，返回或删除后回到原先阅读位置，不再跳回列表顶部；保留搜索条件，列表缩短时自然限制到新的底部。
54. 修复侧栏账户按钮箭头的垂直对齐，随菜单开合使用原有动画参数平滑旋转，并支持减少动态效果。
55. 面试输入框下排的自动回答、截图及发送控件与顶部转写开关统一为 26px 高度。
56. 收紧截图按钮中快捷键和计数的额外留白，保持原有文字、快捷键和展开动画。
57. 本地组件下载按钮保留进度与取消交互，将本地组件首次显示“取消”的保护延迟设为 0.5 秒，避免鼠标停留在原下载按钮上时立刻误取消；其他下载入口保留原有默认延迟。

## 七、语音分段与状态保护

58. 通用逻辑断句的连续静音阈值从 800ms 调整为 1000ms，减少同一句话因短停顿被切成多段；自动回答的 1800ms 截止规则保持。
59. Qwen 沿用原有模型及原生运行时，其内部仍使用 800ms 暂存边界；共享适配层将短停顿的片段作为同一句临时稿续写，按真实音频进度确认逻辑终稿，避免直接把内部短分段全部显示为独立句子。
60. 修正 Qwen 静音起点和已处理音频的计算：按原生边界反推静音起点、等待实际处理确认后推进进度，不把尚未处理的音频算作已完成静音。
61. 软静音或切换方式时按通道隔离已排队、正在处理和迟到的识别结果，清除对应缓存，恢复后使用新的发言边界，避免把切换前后的残片拼接。
62. 保留语音队列、长发言和延迟片段的容量限制；暂停、结束、音频间断及输入切换失败使用明确的取消和回滚流程，不伪造可触发自动回答的静音终稿。
63. 输入切换等待原生确认后再更新界面；与重连、模型切换互斥，跨暂停、结束、导航或新会话的迟到结果不得改变当前状态。单次软静音失败不再误显示为整条音频链路断开。

## 八、撤回方案与代码、文件清理

64. 本轮试作的面对面面试、声音录入、声纹比对、自动／手动说话人区分、学习和身份分配快捷键最终未纳入 Beta 1；相关专用展示、状态、契约、IPC、后端及测试已撤回，最终保留简化的“仅转录”方案。这些不是从已发布 1.0.2 删除的功能。
65. 清除该撤回方案的 GitHub 说话人模型附件及对应发布说明，并删除本地已无消费者的旧说话人模型缓存；现用语音识别与知识库模型保持。
66. 移除无宿主的旧独立工具栏、旧音频复选框及按钮样式，清除没有实际生产者的旧界面元素，而不是仅将其隐藏。
67. 删除已无现行验证入口的旧 SAPI 语料生成器及其唯一配套清单，清除文档中对应的旧命令；现行固定公开音频准备流程及有效音频专项继续使用。
68. 删除被后续规则完全覆盖的胶囊对齐声明，合并开始面试底部说明的重复样式，保留最终显示效果。

## 范围说明

- 本清单不把 1.0.2 已有的 Word／编码导入、同步修复、聊天阅读位置、组件初读骨架及自动回答语气词过滤重复列为新增功能。
- 本版复用原有语音模型，不把本轮分段和状态修复表述为已证明“说话人识别更准”或已达到无延迟识别。
- 外部系统截图只截取较小可视悬浮窗区域的反馈，不在本清单中列为已完成修复；本轮确认的变化是内置截图按钮布局和窗口可视布局稳定性。
- 更新清单与文件清理不包含版本升级、提交、推送、安装包制作或应用发布；当前发行与恢复基线保留。

## 接续验证入口

在 Windows 工作区使用类型、架构、相关单测和共享构建检查；定向界面入口包括 `interview-shortcuts-smoke.mjs`、`interview-motion-smoke.mjs`、`history-scroll-smoke.mjs`。真实识别引擎的输入门控入口为 `speech-input-state-smoke.mjs`，使用校验过的模型缓存和固定公开音频，不采样真实硬件。验证成绩及运行产物不保存在本文或仓库中。
