# VoxCue 0.5.9 · macOS

适用于 Apple Silicon（arm64）、macOS 26 及以上。Mac 安装包与更新包发布于 [v0.5.9](https://github.com/NCFXZ/VoxCue-releases/releases/tag/v0.5.9)；Windows 0.5.9 尚待 Windows 本机验收和后续发行授权，原有 Windows 安装包保持。

## 本次更新

1. ChatGPT 改为一次官方托管登录，聊天、模型目录、续期和账户额度复用同一会话；删除单独连接用量入口。旧版登录可能需要正常重新授权一次，聊天、资料和记录保留。
2. 恢复 GitHub Copilot 官方登录、实际账户模型目录与额度；改进 Auto 的资料提案兼容，保留可靠错误诊断，修复退出后迟到身份读取可能恢复旧会话，以及打包后运行时虚拟路径导致无法启动的问题。
3. 账户用量只显示官方实际返回的窗口、单位、套餐和重置时间；未知/失败不填0，不推算重置日。额度卡改为标题、同排重置/剩余、底部横条；名称统一“5小时额度”“每周额度”。
4. 删除软件主题色调节，强调色跟随系统；Mac 使用官方 AppKit 进度条和菜单。明暗主题切换保持，Windows 共享控件按其平台实现。
5. 调轻账户卡片，收紧姓名/邮箱间距，补齐悬停/键盘反馈；退出确认文字改为红色“退出登录”。
6. 启动Logo阴影跟随透明圆角，VoxCue文字增加柔和扫光；减少动态效果时静态显示，移除底部转圈。
7. 个人信息展开时聊天滚动条变细，收起恢复；输入框换行即时调整高度，聊天和面试停止按钮更清晰。
8. 音频测试移除结束后的有声/无声文字，保留运行音量条、停止与错误提示；面试设置顶部固定并复用聊天材质，后方不再压暗或额外虚化，去掉标题前装饰图标。
9. 发送的面试截图显示在提问气泡内，并归档原图与缩略图至本机记录；纯图片提问更紧凑，标识放在图片下方。未发送草稿不落盘，失败/重试复用原图。
10. 两个面试记录入口可查看原图；查看器标题统一“截图”，保存按钮位于关闭左侧，翻页按钮及胶囊页码悬浮于图片上。支持左右键、两指平移、捏合/Ctrl+滚轮缩放、有界拖拽与双击复位。
11. 仅面试记录可通过系统对话框保存原始图片；面试中隐藏保存且不压暗后方。修复保存按钮命中偏移、悬停位移、关闭残留遮罩、顶部按钮消失及玻璃箭头/页码空白；删除记录清理不再引用的图片。
12. 服务标题统一仅显示“ChatGPT”或“GitHub Copilot”，减轻字重，不再追加Auto/模型/厂商；保存的模型元数据保留。
13. Local RAG 固定为已确认 v7：改善连续追问、换题、比较和项目隔离，退役本地 Function Calling 及知识库设置标签页，保留侧栏知识库管理。增加受控分类重试、同题完整证据复用和索引开场保护，现有模型、索引与原件不迁移。
14. 清理无消费者的旧代码/样式和专用接口，补齐账户、截图、检索及原生回归；Mac/Windows共用布局和业务，平台材质保持分离。
