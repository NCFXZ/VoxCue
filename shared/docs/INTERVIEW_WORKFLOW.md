## 当前行为

- 透明浮窗命中区域由最近一次鼠标移动/抬起位置计算。窗口离开事件只重算该位置，避免原生转发切换后排队的旧坐标覆盖新位置，让输入框重新穿透；按键按下、窗口拖动及缩放期间保持原保护。Windows 原生专项覆盖输入区移动后的旧空白离开事件，结果仅终端/内存；共享实现不复制平台页面，Mac 原生行为留待其本机复核。

- 第二阶段始终保留原窗口内全部真实发言、已提交问题和间断提示，仅按明确主题省略较早无关AI建议，近期和相关完整问答仍保留。口语纠正不依赖关键词识别；“这块/那套/上回”等指代、连续追问或比较即使包含技术名也沿用完整原窗口。仅历史较长且完整载荷缩小至少20%时启用，未展示的建议单独标记。不增加摘要/分类模型调用，不延长静音提交时序，也不承诺找回原120条/64KB边界之外的内容。离线链路入口见 shared/test/README.md，真实模型对照仍取消，离线验证不替代真实答案质量、识别率与网络速度验收。
- 用量优化第一阶段只过滤明确回应的自动生成，保留转写、草稿和手动发送；原2200ms静音提交规则、模型、思考强度与默认篇幅保持。历史只对完全相同长文本作可还原引用，保留角色、时间和追问关系，不新增摘要或截断。精确本地检索缓存按查询/知识库/参数隔离，索引更新、停用、删除、模型卸载或关闭失效；完整证据仍读取，模型每次生成新答案。
- “设置 → 面试设置 → 面试界面”提供字号变大、变小、重置和实时预览。默认 14px，范围 12–24px，每次 1px，独立偏好 voxcue-interview-font-size-v1 在本机保存并同步打开的窗口。仅浮窗转写、问题、回答与输入文字跟随，工具栏、按钮、图标、窗口拖动及缩放几何保持；不会改变历史记录或真实资料。
- 设置增加“面试设置”：左侧系统音频/面试官，右侧麦克风/面试者；麦克风允许禁用，保留设备选择。音频和回答设置本机持久化，仅影响下一场。账户模型和思考强度直接选择，删除“使用 ChatGPT”勾选和转写模式。Mock 会话仍明确模拟，不能冒充真实回答。
- 麦克风测试使用所选设备、原生麦克风单源及活动音量事件；用户显式点击后开始，停止、换设备、禁用、关闭设置或十秒到期后释放。面试期间不能抢占采集。测试文字不回填聊天或写入记录，音频不保存。加载期间也可取消。
- “低 · 更快”统一显示“轻度”。模型支持时初次默认 low，未知能力使用 auto；用户明确保存的 auto 不会在开场时改回 low。确认弹窗仅保留必要采集/发送说明、取消和开始，不再提供设置控件。
- 浮窗输入框左下放“自动回答”胶囊开关，控制静音后提交，可在本场随时切换。关闭立即取消待提交计时。自动提交只使用系统音频终稿；麦克风只作面试者记录。
- 系统音频临时转写与未提交终稿实时组成输入框草稿，用户可直接发送，不必等静音终稿。手动发送消费已有缓冲，标记已提交临时段；该段迟到终稿不重复进入下一题。用户手工编辑时保留其草稿，发送后恢复实时跟随。
- 回答面板右上放“转写”胶囊开关。顶部移除转写和置顶操作；原生窗口固定置顶。品牌整块可收起/展开，顶部右侧 Fluent 拖拽图标是独立拖动区，面板标题和其他工具栏区域不再拖动。
- 底角仅在悬停/聚焦时显示缩放图标，按住拖动调整尺寸。主进程从系统指针和起始窗口计算尺寸，水平方向对称缩放；面板与顶部保持同一中心。收起采用紧凑原生窗口，同时补偿横坐标；展开还原尺寸，保持工具栏绝对中心和顶部位置。保留旧数字 resize 调用以兼容测试/既有接口，界面只提供拖动方式。
- 首次结束点击展开红色“确认结束”，宽度与背景连续过渡；三秒未确认自动收回，需重新二次确认。移除旁边取消图标。系统关闭同样走此流程；确认后等待尾段、保存记录再关闭。保留错误提示，删除正常状态底部保护说明。
- 主界面切页保持准备聊天组件、输入草稿和滚动位置；切换/新建对话不取消当前请求。Zustand 按发起对话 ID 更新后台消息，不把增量写入另一对话。显式停止、删除正在生成的对话及退出仍可取消。本轮没有增加并行模型请求；后台请求未完成时发送按钮仍受单请求约束。
- 正式回答前显示默认收起的“推理摘要”。仅接收公开 Responses `reasoning_summary_text`/`summary_text` 事件及终态摘要，支持 SSE 和完整 JSON 校准；不转发原始 `reasoning_text` 或 `encrypted_content`。已知推理模型请求 `summary: auto`，实际是否返回取决于服务/模型；没有摘要时不编造。根据 [OpenAI 推理模型说明](https://developers.openai.com/api/docs/guides/reasoning) 和 [流式事件定义](https://developers.openai.com/api/reference/resources/responses/streaming-events) 实施。
- 主聊天及浮窗仅在读者接近底部时跟随流式内容；向上滚轮、键盘或滚动条阅读后停止自动拉底，重新回到底部恢复跟随。

## 边界

`interviewSettings` 仅存音频设备、模型/effort；原始资料仍在既有 IndexedDB。`SpeechControls` 是设置展示，`SpeechCoordinator` 继续串行管理采集归属。DictationCall 新增可选 microphone ID，主进程按现有音频设备校验，始终固定麦克风来源。resize 新增 start/move/end 手势类型，主进程校验调用窗口/主 frame，使用系统指针而非任意 Renderer bounds。renderer 沙箱、凭据、OAuth 和保护功能范围未扩大。
