# VoxCue for Windows

VoxCue 是本地 Windows 桌面面试准备应用，支持 ChatGPT 浏览器登录、准备聊天、个人信息与简历、本地知识库、语音转写和面试记录。

VoxCue 使用 AGPL-3.0-only 许可证。源码和 Windows 安装包均可从 [GitHub 项目](https://github.com/NCFXZ/VoxCue) 获取。

## 下载与安装

1. 打开 [GitHub 发行页](https://github.com/NCFXZ/VoxCue/releases)，选择含 Windows x64 安装包的最新正式版本。
2. 下载 `VoxCue-Setup-<版本>-x64.exe` 并运行，按安装向导完成安装。
3. 从桌面或开始菜单打开 **VoxCue**。

适用于 Windows 10/11 x64。安装包包含所需运行库，无需另外安装 Python、Node.js、WSL 或开发工具。语音和知识库模型在“设置 → 本地组件”首次下载，后续升级复用缓存。当前安装包未进行代码签名，Windows 可能显示“未知发布者”。

用户只需下载安装程序 `.exe`；`.blockmap` 和 `latest.yml` 是应用自动更新所用文件。

## 开始使用

1. 登录 VoxCue 或选择本地模式。在 **设置 → AI 服务** 中选择 ChatGPT 或 GitHub Copilot 账号授权，或选择 API 服务商并在密钥输入框中配置连接。可用模型和功能由所选连接的实际权限决定。
2. 在 **个人信息** 中填写姓名与面试语言，展开相应分区并使用编辑弹窗更新简历、职位描述、自定义指令或技能，按需选择知识库。AI 生成的资料提案需确认后保存。
3. 在准备页输入问题开始聊天；可使用附件、模型和思考强度菜单。聊天、草稿及附件保存在本机。
4. 打开 **设置 → 面试设置**，确认播放设备、麦克风（可选择“不使用麦克风”）、语音模型、推理设备、回答模型和思考强度。Paraformer 使用 CPU；Qwen 可使用 CPU，硬件与驱动支持时可选 CUDA。
5. 点击 **开始面试**，核对本场设置后确认开始。开启自动回答时，远程面试从系统音频识别问题，现场面试从麦克风识别问题。也可手动提交问题。
6. 结束后在 **面试记录** 中查看转写、回答与已提交的截图。可导出文字，也可回放或单独导出本场保存的 WAV 录音。

使用浮窗的截图按钮可将当前画面添加到草稿，每个问题最多五张。可先移除不需要的截图，再提交给所选模型。

语音识别在本机运行。自动录音默认关闭，可在面试中手动开始或停止。录音仅保存在本机当前账号下，不进入云备份。提交问题时，必要文字、所选资料片段及随问题提交的截图会发送至所选 AI 服务。语音识别效果受设备、噪声和语言混读影响，使用耳机可减少回录。

## 更新

安装版启动后会检查新版本。也可打开 **设置 → 关于与更新** 检查和下载，然后点击 **重启并更新**。面试进行中无法安装更新。更新保留本机资料、聊天和记录，关闭应用不会自动安装更新。

Windows x64 客户端按本平台选择含安装程序、更新清单和 blockmap 的最新完整正式发行。1.2.2 使用源码仓库检查更新，旧客户端仍从 [兼容发行仓库](https://github.com/NCFXZ/VoxCue-releases/releases) 获取更新。Microsoft Store 版由商店更新。

Windows Qwen 组件 1.0.1 使用原始 BF16 ASR、Q8_0 对齐器和 Runtime 1.0.1，并使用新的受管缓存；需要在“设置 → 本地组件”下载当前组件。旧组件缓存与旧公开资源保留，任一语音模型就绪即可满足语音模型要求，知识库组件独立检查。

如果使用旧开发版或便携版，请先手动安装这个安装包；以后使用应用内更新。已经安装同版本旧测试包时，重新运行最新安装程序以替换程序文件。

## 卸载

Windows 安装包提供“保留用户数据”复选框，默认勾选；取消勾选后点击卸载即删除，无二次确认。范围为本机 VoxCue 的聊天、个人资料、知识库、设置和模型缓存，外部原件保持。应用更新继续保留用户数据，安装范围仅当前 Windows 用户。

首次安装提供默认路径 `%LOCALAPPDATA%\Programs\VoxCue`，可通过“选择”按钮选择其他位置；检测到已安装版本时显示原路径，选择按钮置灰，覆盖安装和更新保留原目录。
