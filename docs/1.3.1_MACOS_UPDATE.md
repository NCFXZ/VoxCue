# VoxCue 1.3.1

## 新功能

- 可在同一台电脑的账号间迁移个人信息、面试记录和知识库。
- 资料冲突可按整场面试或整个知识库选择云端、本地版本。
- 聊天和面试可用 API 密钥连接八家服务商，多个面试准备对话可同时生成回答。
- 面试支持本地录音、回放和 WAV 导出。面试中可立即切换语音识别模型，也可取消切换。

## 问题修复

- 修复了语音积压时从 CPU 切换到 Metal，以及系统信号打断音频写入时，采集可能停止的问题。
- 修复了展开或收起面试窗口时的闪烁，以及长转写、长回答中 Home 和 End 滚动失效的问题。
- 资料迁移中断后可继续清理来源，更新包损坏后可直接重试下载。
- 补齐了英文界面的语音采集时钟异常和转写恢复提示。

适用于运行 macOS 14.2 及以上版本的 Apple Silicon Mac。首次安装请下载 DMG。安装包使用项目固定签名，未经 Apple 公证。

## New Features

- Transfer profile information, interview records, and knowledge bases between accounts on the same computer.
- When resolving a conflict, choose whether to keep the cloud or local version of an entire interview or knowledge base.
- Use API keys to connect chat and interviews to any of eight AI providers. Multiple interview prep chats can generate responses at the same time.
- Record interviews locally, play them back, and export them as WAV files. During an interview, you can switch speech recognition models immediately or cancel a pending switch.

## Bug Fixes

- Fixed audio capture stopping when switching from CPU to Metal during a transcription backlog or when a system signal interrupted an audio write.
- Fixed flickering when expanding or collapsing the interview window. Home and End now scroll correctly in long transcripts and answers.
- Interrupted migrations can now resume cleaning up the source account. If an update package is damaged, you can retry the download.
- Added the missing English messages for audio capture clock errors and transcription recovery.

Requires an Apple Silicon Mac running macOS 14.2 or later. For a first-time installation, download the DMG. The installer is signed with the project’s certificate and has not been notarized by Apple.
