# VoxCue 1.3.0 Windows 更新日志

- 可在同一台电脑的账户间迁移所选资料。
- 迁移其他 VoxCue 账号的资料前，会验证来源账号密码。
- 注销时遇到断网，重开应用可确认注销结果。
- 聊天和面试新增八家 API 服务商。
- 开始面试前可查看 API 服务商和计费方式。
- 可查看每条 AI 回答来自哪家服务商。
- 多个准备对话可同时生成回答。
- 开始面试前可查看实时音量。
- 面试中可立即切换语音模型，也可取消切换。
- 可在本机录制面试，复盘时回放或导出录音。
- 每个问题最多可附五张截图，复盘时可查看原图。
- 开启面试记录同步后，面试结束会自动续传。

提升了知识库检索、手机连接和应用运行的稳定性。

**语音识别已知限制**　极短追问可能漏字，语气词误识别可能触发自动回答并消耗额度。可关闭「自动回答」，核对后手动发送。
